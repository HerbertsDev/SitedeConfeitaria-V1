# Mércia Bolos — V1

Primeira versão do projeto de uma confeitaria artesanal especializada em bolos de pote e bolos por quilo. Desenvolvido para praticar fundamentos de desenvolvimento web e compor meu portfólio.

## Funcionalidades

- Página inicial responsiva;
- Catálogo de produtos em destaque;
- Menu adaptado para dispositivos móveis;
- Apresentação do processo de encomenda;
- Formulário demonstrativo com validação;
- Identidade visual própria e conteúdo acessível.

## Tecnologias

- HTML5 semântico;
- CSS3, Flexbox e CSS Grid;
- JavaScript;
- Git e GitHub.

## Estrutura

```text
mercia-confeitaria/
├── css/           estilos do site
├── img/           imagens utilizadas
├── js/            comportamentos da página
├── .gitignore     arquivos ignorados pelo Git
├── index.html     página principal
└── README.md      documentação do projeto
```

## Executar localmente

Abra o arquivo `index.html` no navegador ou utilize uma extensão de servidor local no editor.
